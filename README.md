# ALEPlot

Accumulated local effects and partial dependence plots for fitted models.

Compatibility updates by Renova.

Uses single-class comparisons in plot dispatch and adds structured author metadata.

## Installation

```r
install.packages("ALEPlot", repos = c(
  Renova = "https://renova-r.r-universe.dev",
  CRAN = "https://cloud.r-project.org"
))
```

Version `1.1.9001` is based on [CRAN 1.1](https://cran.r-project.org/package=ALEPlot).
